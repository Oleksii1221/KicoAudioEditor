# Support

Use GitHub Issues for KAE support requests, bug reports, and feature ideas.

Before opening an issue:

1. Check the latest release.
2. Confirm the file format is supported.
3. Avoid attaching copyrighted audio files unless you own the rights.
4. Include your operating system and KAE version.

Release downloads are available at:

https://github.com/Oleksii1221/KicoAudioEditor/releases
