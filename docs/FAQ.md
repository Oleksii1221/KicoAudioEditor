# FAQ

## Is KAE a web app?

No. KAE is a native desktop application built with PySide6.

## Does KAE upload my music?

No. KAE works locally and does not include telemetry or server sync.

## Which files should I download?

Use `KAE-Setup-<version>.exe` on Windows. On Linux, use AppImage for a universal package, `.deb` for Ubuntu/Debian, and `.rpm` for Fedora/RHEL.

## Why are Linux packages large?

KAE bundles a Python and Qt runtime so the application can run consistently across distributions.

## Can I use KAE for copyrighted music?

Use KAE only with files you have the right to edit and manage.
